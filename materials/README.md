# Дополнительные материалы курса (`materials/`)

В этой папке хранятся исходные учебные материалы I семестра, по которым составлен и выверен конспект в `src/`.

| Файл | Обозначение в тексте | Описание |
| --- | :---: | --- |
| `I Семестр (теоретические вопросы).pdf` | `[Т]` | Официальный список из 42 экзаменационных теоретических вопросов (21 билет) |
| `Лекции (I семестр).pdf` | `[Л]` | Полный курс лекций по математическому анализу I семестра (56 с., 13 лекций) |
| `matan.pdf` | `[К]` | Краткий конспект первой половины курса — до равномерной непрерывности включительно (33 с.) |
| `Сборник задач и упражнений по математическому анализу для вузов (2005) — Б.П. Демидович.pdf` | `[Д]` | Задачник Б. П. Демидовича (2005, 561 с.) — все номера задач и параграфов сверены по этому изданию |
| `Математический анализ (часть 1, издание 10, 2019) — В.А. Зорич.pdf` | `[З]` | Учебник В. А. Зорича, ч. I (10-е изд., 2019, 576 с.) — для строгого справочника и темы комплексных чисел |
| `Математический анализ — объединённый конспект лекций.md` | — | Объединённый конспект лекций в Markdown (28 разделов: множества и отображения, аксиомы ℝ, пределы, непрерывность, производная, Тейлор, исследование функций). Дополняет гайд в `src/`: даёт фоновую теорию (в т. ч. счётные множества и континуум) и сводные доказательства из двух источников. Удобен для чтения в Obsidian. |

> **Примечание о Git:** в корневом `.gitignore` добавлено правило `*.pdf`, поэтому тяжёлые учебники и сканы из `materials/` не попадают в коммиты и не перегружают удалённый репозиторий, оставаясь доступными локально.
