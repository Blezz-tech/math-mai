# Математический анализ. I семестр — Билеты и план подготовки

Структурированный учебный справочник для подготовки к экзамену, зачёту и контрольным работам по математическому анализу за I семестр, свёрстанный на **[Typst](https://typst.app/)**.

Охватывает **все 42 теоретических вопроса (21 билет)** с точными формулировками, полными доказательствами, примерами, «ловушками билета», сверенным разбором задач из **Б. П. Демидовича (2005)**, **11 вариантами контрольной работы**, **одностраничной шпаргалкой формул** и пошаговым планом подготовки к сессии.

---

## Содержание справочника (33 страницы PDF)

1. **Сводная карта источников** — что покрывают лекции, конспект `matan.pdf`, список вопросов, практика, Демидович и Зорич; где пробелы и несостыковки (в т. ч. комплексные числа и высшие производные).
2. **Сравнение с учебником В. А. Зорича** — компактная карта глав II–V: какие параграфы брать к экзамену, что можно пропустить до II семестра и где различаются формулировки.
3. **21 экзаменационный билет (42 вопроса + задачи Демидовича):**
   - Билеты 1–6: аксиоматика $\mathbb{R}$, точные грани, принцип Архимеда, лемма Коши–Кантора, Борель–Лебег, Больцано–Вейерштрасс, предел последовательности, критерий Коши, число $e$, $\liminf$ и $\limsup$.
   - Билеты 7–12: предел функции (Гейне и Коши), арифметика и неравенства, композиция, б.м./б.б., 1-й и 2-й замечательные пределы, монотонные функции, О-о символика, непрерывность и классификация разрывов.
   - Билеты 13–15: глобальные теоремы (Больцано–Коши, Вейерштрасс, обратная функция), равномерная непрерывность, теорема Кантора, модуль непрерывности.
   - Билеты 16–18 + **11 вариантов контрольной работы**: производная, дифференцируемость, дифференциал, цепное правило, обратная и параметрическая производные, таблица производных, теоремы Ролля, Лагранжа и Коши.
   - Билеты 19–21: правила Лопиталя, формула Тейлора с остатками в формах Лагранжа, Коши и Пеано, таблица разложений Маклорена, монотонность, экстремумы, выпуклость и перегибы.
4. **Шпаргалка формул (ровно 1 страница A4)** — готова к печати на одном листе.
5. **План подготовки к сессии** — разбивка по 5 фазам, контрольные точки и экспресс-режим на 7 дней.
6. **Чек-лист готовности, советы к ответу и Приложение** со сводным списком номеров Демидовича по всем 17 занятиям практики.

## Как собрать PDF локально

### 1. Установить Typst

- **Windows (winget / scoop):** `winget install --id Typst.Typst` или `scoop install typst`
- **macOS (Homebrew):** `brew install typst`
- **Linux / кроссплатформенно (Cargo / Python):** `cargo install --locked typst-cli` или `pip install typst`
- **VS Code:** расширение **Tinymist Typst** (даёт живой предпросмотр, автодополнение и экспорт в PDF прямо в редакторе).

Шрифт **New Computer Modern** встроен прямо в компилятор Typst — дополнительно ставить шрифты не нужно.

### 2. Скомпилировать документ

**Напрямую через Typst (работает на любой ОС):**

```bash
mkdir -p dist
typst compile src/main.typ "dist/Математический анализ I семестр — Билеты и план подготовки.pdf"
```

**Режим автопересборки при редактировании:**

```bash
typst watch src/main.typ "dist/Математический анализ I семестр — Билеты и план подготовки.pdf"
```

**Или через `Makefile` (Linux / macOS / Git Bash):**

```bash
make build   # собрать PDF в dist/
make watch   # пересобирать на лету при сохранении файлов в src/
make clean   # удалить папку dist/
```

## Работа с Git и `.gitignore`

Репозиторий уже инициализирован на ветке `main` с базовым коммитом.

- В `.gitignore` включено правило **`*.pdf`** (и папка `dist/`):
  - пересобранный PDF не захламляет историю коммитов бинарными диффами;
  - тяжёлые учебники и сканы в `materials/` (~18,5 МБ) остаются у тебя локально и **не загружаются** на GitHub.
- При желании на GitHub сработает готовый workflow `.github/workflows/build.yml` — он автоматически скомпилирует свежий PDF после каждого `push` в `main` и прикрепит его к артефактам сборки.

### Как залить репозиторий на GitHub / GitLab

```bash
cd matan-sem1-guide
git status                             # рабочее дерево чистое (PDF уже в .gitignore)
git remote add origin <URL-твоего-репозитория>
git push -u origin main
```

## Как вносить правки

- Оформление, палитра, макросы (`tg`, `ctg`, `arctg`, `liminf`, `limsup`, блоки `#proof`, `#example`, `#trap`, `#control_variant`) — в **`src/template.typ`**.
- Текст конкретных билетов, доказательств и задач — в соответствующем файле внутри **`src/sections/`**.
- Порядок разделов — в **`src/main.typ`**.
